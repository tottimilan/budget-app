# budget-app

Pequeña app para comparar coste por **litro** vs **galón**.

## Uso

1. Ingresa el coste de 1 litro.
2. Ingresa el coste de 1 galón.
3. Pulsa **Comparar** para ver:
   - coste por litro equivalente del galón,
   - diferencia por litro,
   - qué opción conviene más.

> Conversión usada: **1 galón = 3.78541 litros**.
